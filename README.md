# dsh-plugin-update

给 AI 代理用的技能：更新 DeepSeek Harness（DSH）第三方插件的操作指南。

## 内容来源

本技能内容只来自 DeepSeek Harness 官方文档（[官方仓库](https://github.com/deepseek-ai/deepseek-harness)），并在 SKILL.md 开头强制要求每次使用前先联网核对官方最新文档。官方文档变更时以官方为准。

## 安装

把整个 `dsh-plugin-update` 文件夹复制到你的技能目录（AI 工具读取 `SKILL.md` 的目录）。常见位置：

- `%USERPROFILE%\.workbuddy\skills\`
- `%USERPROFILE%\.dsh\skills\`

具体以你的 AI 工具配置为准，放入后重启工具即可在技能列表看到。

## 适用场景

- 更新桌面版 DSH 的第三方插件
- 插件市场里点更新报错
- 查询哪些插件有新版本、回滚插件
- 不清楚 `dsh plugin` 命令怎么用
